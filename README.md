# Missão Rover Lunar

## Descrição do Projeto
Este projeto simula a inicialização dos sistemas de um Rover Lunar. O repositório foi criado como parte de uma atividade prática da disciplina de **Garantia da Qualidade de Software (GQS)**, ministrada pelo Professor Daniel Henrique Matos de Paiva.

O objetivo principal desta missão é exercitar o fluxo de versionamento utilizando Git e GitHub, incluindo:
- Criação de repositórios.
- Gestão e fluxo de branches (`develop` para `main`).
- Commits padronizados.
- Criação, revisão e aprovação de Pull Requests (PR).

O algoritmo de inicialização do rover foi desenvolvido na linguagem **Java**.
